# Contribute to the atlas

[Open an issue or contribute on GitHub](https://github.com/seafelsayed/ai-career-atlas).

For a new role, include an employer source, the exact title, the date checked, a paraphrase of the work, and the distinction from existing roles. Label generalizations and learning advice as editorial interpretation. Do not infer industry growth from a handful of job listings.

To correct an existing profile, link the source and describe what changed. Please do not submit personal applicant data or private employer materials.

## Current research peer review

See the [reviewer trace task](/career-research#reviewer-task) and [decision record](/review-record). For the current T-shirt and career/portfolio research round, file 3–5 constructive GitHub issues per classmate, per project. Each issue needs a specific observation, why it matters, and a useful next step with a relevant page, source, or example.

Accepted feedback requires a linked commit/PR referencing the issue, actual verification, and reviewer retry before closure. Keep unfinished work open with a next step. Private career reflections and personal eligibility circumstances belong in Canvas.
