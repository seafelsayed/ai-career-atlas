# AI Evaluation Engineer

> **Focus:** Quality & safeguards · **Evidence reviewed:** November 5, 2026

## What the role is for

Create repeatable ways to understand model capabilities, weaknesses, and regressions.

## Skills to investigate

Test design, statistics, data analysis, reproducible experiments, and engineering.

## Typical work product

A versioned evaluation dataset, scoring rubric, and regression report.

## Portfolio idea

Create an evaluation harness for a document assistant, including unsupported answers and adversarial inputs.

This project is an editorial practice suggestion, not an employer hiring requirement.

## Questions to ask before applying

- What does success look like in the first 90 days?
- How much time goes into coding, customer work, experimentation, and coordination?
- Who owns production quality, data access, and ongoing maintenance?
- What experience is required rather than preferred?

The sourced example is cyber-focused. Other evaluation jobs can require very different domain expertise.
