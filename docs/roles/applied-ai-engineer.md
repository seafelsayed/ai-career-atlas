# Applied AI Engineer

> **Focus:** Application building · **Evidence reviewed:** November 5, 2026

## What the role is for

Turn model capabilities into useful application features and repeatable workflows.

## Skills to investigate

Python or TypeScript, model APIs, retrieval, testing, and production software practices.

## Typical work product

A working AI feature with evaluation examples, observable failures, and operating documentation.

## Portfolio idea

Build a cited document assistant. Compare retrieval approaches using a small labeled question set.

This project is an editorial practice suggestion, not an employer hiring requirement.

## Questions to ask before applying

- What does success look like in the first 90 days?
- How much time goes into coding, customer work, experimentation, and coordination?
- Who owns production quality, data access, and ongoing maintenance?
- What experience is required rather than preferred?

Scope varies: some roles are customer-facing, while others own internal product engineering.
